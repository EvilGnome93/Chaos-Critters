# Chaos Critters — Pet Image Prompts

Basisstijl die je aan elke prompt toevoegt, zodat alle pets als collectie bij elkaar passen.

## Vaste artstijl (aan elke prompt toevoegen)

```
Digital illustration, semi-flat cartoon style with clean bold outlines,
soft cel-shading, vibrant saturated colors, centered composition,
simple neutral background (light gradient), square 1:1 aspect ratio,
game trading-card creature art style, friendly and slightly quirky
character design, no text, no watermark
```

## Tier-indicatie (optioneel toevoegen voor visuele herkenning)

- **Tier 1 (Common)**: `subtle simple background, calm pose`
- **Tier 3 (Rare)**: `soft glowing outline accent, dynamic pose`
- **Tier 5 (Legendary)**: `golden glowing aura, dramatic pose, particle effects`

## Gebruik

Vervang `[artstijl]` in elke prompt met de volledige vaste artstijl-tekst bovenaan. Zo blijft elke pet visueel consistent, ook als je ze los van elkaar genereert of later meer pets toevoegt.
